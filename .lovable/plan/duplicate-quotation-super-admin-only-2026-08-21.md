# Duplicate Quotation (Super Admin only)

## Goal
Add a "Duplicate quotation" action in the quotation list so a super admin can create a new quotation that copies an existing one, instead of re-entering every line item.

## Behaviour
- New menu entry **Duplicate** appears in the per-quotation actions menu inside a lead's Quotations section.
- Visible only to users with the `super_admin` role. Everyone else does not see it at all.
- Clicking it opens the quotation builder pre-filled with the source quotation's customer, subject, notes, terms, currency and all line items (model number, description, qty, rate, discount, tax).
- The copy is a brand-new quotation: fresh quotation number (generated by the database sequence), status starts as draft/pending, no email history, no price-matched flag, validity date left for the user to set.
- The original quotation is untouched. Saving the copy is an explicit action, so an accidental click creates nothing.
- Confirmation toast on save naming the new quotation number.

## Technical notes
- Gate with `hasRole('super_admin')` from `useAuth` (not `isAdmin`, which also includes COO).
- Add the item to the existing dropdown in `src/components/leads/LeadQuotationsSection.tsx`, next to View / Edit / Download.
- Reuse `CreateQuotationDialog` + `QuotationBuilder` with `prePopulatedItems` derived from the source quotation's items (fetched via `useQuotation` / `ensureItemsWithModelNumber` so model numbers are present), and pass the source customer/lead context.
- No database or RLS changes: creation goes through the existing `useCreateQuotation` path, so document numbering, tenant scoping and activity logging stay as they are.

## Out of scope
- Duplicating across a different lead or customer.
- Duplicate action on the supplier-quotation screens.
